# flaga_events

The event layer of flaga: `FlagEvent` and `TriggerStrategy`, `FlagEventManager`, `FlagTrigger`, and the `Feature` / `FeatureManager` registry. Built on `flaga_core`.

Most people want the [`flaga`](https://crates.io/crates/flaga) facade crate, which re-exports this crate under the old paths.
